# Crédits

## Code
- Tout le code du jeu est original.

## Assets visuels
- Toutes les textures (drone, ennemis, ressources, tuiles, silhouette de ville, effets)
  sont générées par code à l'exécution (Phaser Graphics / Canvas API). Aucune image
  externe n'est utilisée : aucune licence d'asset graphique à gérer.

## Audio
- Tous les sons et l'ambiance sonore sont générés par synthèse (Web Audio API,
  oscillateurs et bruit filtré). Aucun fichier audio externe n'est utilisé.
